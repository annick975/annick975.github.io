# Dream Travel Destinations 🌎✈️

This project is a **minimalist travel showcase** highlighting 5 stunning destinations from around the world. Built using **HTML & CSS only**, it features a clean, modern design that lets the beautiful destination images speak for themselves.

## 🚀 Features

- **Minimalist Hero Header** – Simple title introducing the travel destinations concept
- **Destination Showcase** – Five full-screen sections featuring:
  - Santorini, Greece
  - Kyoto, Japan
  - Machu Picchu, Peru
  - Bora Bora, French Polynesia
  - Serengeti, Tanzania
- **Clean Design** – Uncluttered layout with brief descriptions and simple buttons
- **Responsive Layout** – Adapts to any screen size for optimal viewing

## 🎨 Tech Stack

- **HTML5** – Structure of the page
- **CSS3** – Minimalist styling and layout
- **Google Fonts** – Montserrat font family
- **Unsplash** – High-quality destination images

## 🔥 How to Run

   ```bash
   git clone https://github.com/annick975/annick975.github.io.git
   ```
