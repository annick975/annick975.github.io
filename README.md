# Chelsea FC Tribute Page ⚽💙  

This project is part of the **Hack & Slice 1-Month Coding Challenge** hosted by **Youth Code Camp (https://github.com/Youth-codecamp)**. It is a **tribute webpage** dedicated to **Chelsea Football Club**, highlighting its history, legendary players, and achievements. Built using **HTML & CSS only**.  

## 🚀 Features  

- **Hero Section** – Showcasing the Chelsea FC logo and "London is Blue" tagline.  
- **Club History** – Timeline of Chelsea’s major milestones.  
- **Trophy Cabinet** – Display of Chelsea’s major trophies.  
- **Legendary Players** – Cards featuring club legends like Drogba, Lampard, Terry, Hazard, Zola, and Čech.    
- **Greatest Matches** – Highlighting historic Chelsea games.  
- **Fan Wall & Chants** – Dedicated section for Chelsea fan culture.  

## 🎨 Tech Stack  

- **HTML5** – Structure of the page.  
- **CSS3** – Styling and layout.  
- **GitHub Pages** – Hosting the project.
